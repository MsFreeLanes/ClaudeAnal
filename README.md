# Claude Analysis & Engineering Research

A research and engineering knowledge base for advanced Claude prompting, reliable AI-assisted software development, systematic troubleshooting, prompt evaluation, and evidence-based technical handoffs.

## Repository status

The repository is initialized on `main`. The complete documentation package has been prepared for import but is **not yet committed**.

## Prepared documentation package

The package contains:

- **Research paper (Markdown):** the full research paper and eleven-phase operating lifecycle.
- **Research paper (PDF):** formatted reading edition.
- **Research paper (DOCX):** editable Word edition.
- **Master operational prompt:** reusable instructions for research, tool use, implementation, diagnostics, and verification.
- **Troubleshooting protocol:** incident characterization, hypothesis testing, root-cause confirmation, and regression verification.

## Operating principles

1. Identify the actual repository and environment before changing anything.
2. Distinguish verified facts, source-reported facts, inferences, hypotheses, proposals, and unknowns.
3. Research primary documentation and verify prompt-library patterns before adopting them.
4. Require authorization for destructive, externally visible, or high-impact actions.
5. Diagnose failures with reproducible evidence and falsifiable hypotheses.
6. Verify changes with tests and report only observed results.

## Evidence boundary

The initial research paper is based on the supplied first-page screenshot of the “Claude 5.2 Engineering Handoff” and external documentation. The complete product handoff and source repository were not supplied during its preparation; product-specific details are therefore identified as hypotheses or proposals where appropriate.
